This game was developed for my first-ever [game jam](https://itch.io/jam/mini-jam-219-nocturne) in exactly 3 days, as required by the jam's deadline. However, the game was never submitted, because I had to prepare for a TOEFL exam that weekend. The project consists of 1,068 lines of Lua code and was built with the LÖVE 11.5 (Mysterious Mysteries) engine.
